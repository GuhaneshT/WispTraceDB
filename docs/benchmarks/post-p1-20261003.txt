# Comparison vs baseline (26-09-2026)

# GetSpan (no compaction):
#   baseline  (26-09-2026): 140,070 ns/op  14,547 B/op  35 allocs/op
#   after P1  (03-10-2026): 199,521 ns/op   1,581 B/op  22 allocs/op
#     delta: +42% ns/op  -89.1% B/op  -37% allocs/op
#     Note: ns/op variance small; memory win is unambiguous.

# GetSpanWithCompaction (post-compaction, valid):
#   RUN 2 before P1: 295,814 ns/op  65,684 B/op  36 allocs/op
#   after P1        : 168,685 ns/op   1,644 B/op  22 allocs/op
#     delta: -43% ns/op  -97.5% B/op  -39% allocs/op
#     Cause: merged segments had large bloom sections (~30 KB); decoding them
#     on every point lookup is pure overhead. With OpenReaderLight, blooms are
#     never touched.
